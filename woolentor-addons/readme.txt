== Description ==

**ShopLentor** (formerly WooLentor) is a powerful **WooCommerce builder** for **Elementor and Gutenberg**. Build custom shop pages, product pages, cart, checkout, and my account pages — all with **drag-and-drop**. Includes wishlist, compare, variation swatches, and 37+ built-in modules.

== Installation ==

= 1) Install =

**From your WordPress dashboard:**

1. Go to **Plugins → Add New**.
2. Search for **ShopLentor**.
3. Click **Install Now**, then **Activate**.

**Or upload manually:**

1. Unzip the package and upload the `woolentor-addons` folder to `/wp-content/plugins/`.
2. Activate ShopLentor from the **Plugins** menu.

= 2) Set up =

1. After activation the **Setup Wizard** opens automatically. It walks you through choosing which modules to enable — you can change any of this later.
2. Manage everything from **Dashboard → ShopLentor → Modules**. Each module is a single toggle.
3. To build pages, go to **ShopLentor → Template Builder → Add New Template**, choose a template type (Shop, Product, Cart, Checkout, My Account, Thank You), and edit it with **Elementor** or the **Block Editor**.
4. Elementor users will find a **ShopLentor** category in the widget panel. Block editor users will find ShopLentor blocks under **WL:** in the block inserter.

WooCommerce is required. **Elementor Pro is not** — ShopLentor works with the free Elementor plugin, with Gutenberg, or with both.

== Frequently Asked Questions ==

= What are the minimum requirements for using ShopLentor? =

* WordPress 6.0 or higher
* PHP 7.4 or higher
* WooCommerce (latest version recommended)

ShopLentor is tested against the latest WordPress and WooCommerce releases with every update, and is fully compatible with **HPOS (High-Performance Order Storage)**.

= Do I need Elementor Pro to use ShopLentor? =

No. ShopLentor works with the **free** version of Elementor, and it also works entirely without Elementor thanks to its 45 native Gutenberg blocks in the free version (89 with Pro). Elementor Pro is never required.

= Which features are free and which need Pro? =

The free version includes 18 modules — Free Shipping Bar, Abandoned Cart, Wishlist, Product Compare, Variation Swatches, Ajax Search, Currency Switcher, Sales Notification, Flash Sale Countdown, Shopify Style Checkout, Popup Builder, Backorder Management, Rename Label, Post Duplicator, Product Stock Progress Bar, Single Product Ajax Cart, Redirect to Checkout and Grid/List View Toggle — plus 130+ Elementor widgets and 45 Gutenberg blocks.

Pro adds 20+ further modules (Checkout Field Manager, Multi-Step Checkout, Order Bump, Product Filter, Email Customizer, Email Automation, Size Chart, Quick View, Product Badges, Advanced Coupon and more), the cart, checkout, my account, thank you and email builders, and the full 89-block library. See the **[full comparison](https://woolentor.com/pricing/?utm_source=wprepo&utm_medium=freeplugin&utm_campaign=comparison)**.

= Can I use ShopLentor without WooCommerce? =

No. ShopLentor extends WooCommerce, so WooCommerce must be installed and active.

= Will ShopLentor slow down my store? =

No. ShopLentor is modular: every feature is a separate toggle, and assets for disabled modules and unused widgets are never loaded. Enable only what your store needs and the rest costs you nothing.

= Does ShopLentor work with my theme? =

Yes. ShopLentor works with any WooCommerce-compatible theme, including block themes and full-site editing. Wishlist, Compare, Quick View and the cart widgets are all tested against block themes.

= Can I use ShopLentor alongside other Elementor and WooCommerce plugins? =

Yes. ShopLentor is built to coexist with other Elementor addons and WooCommerce extensions. Because it replaces many single-purpose plugins, most users find they can deactivate several others after installing it.

= How does ShopLentor compare with other WooCommerce Elementor addons? =

ShopLentor is more than a widget pack. Alongside 130+ Elementor widgets and 89 Gutenberg blocks, you get 37+ standalone modules — wishlist, compare, variation swatches, abandoned cart recovery, multi-currency, free shipping bar and more — that would otherwise mean installing a separate plugin for each.

= How do I add a free shipping progress bar in WooCommerce? =

1. Go to **Dashboard → ShopLentor → Modules** and enable **Free Shipping Bar**.
2. Open **ShopLentor → Free Shipping Bar** and set your threshold, or leave it at 0 to auto-detect from your WooCommerce shipping zones.
3. Choose the bar position (top or bottom) and write your progress and success messages.

You can also place the bar inline anywhere using the `[woolentor_free_shipping_bar]` shortcode, the Elementor widget, or the Gutenberg block. [Full documentation](https://woolentor.com/free-shipping-bar-for-woocommerce/?utm_source=wprepo&utm_medium=freeplugin&utm_campaign=faq).

= How do I create a WooCommerce hero banner with Elementor? =

Drag the **WL: Hero Banner** widget onto any page, then pick a style — Modern, Luxury, Editorial or Magazine. Each style includes multiple ready layouts (6 free, 12 with Pro), and you can add as many slides as you need using the built-in repeater.

= How do I add a wishlist in WooCommerce? =

1. Go to **Dashboard → ShopLentor → Modules** and enable **Wishlist**.
2. Open **ShopLentor → Wishlist** to configure the button, table columns and share options.

[Documentation](https://woolentor.com/doc/wishlist-for-woocommerce/)

= How do I compare products in WooCommerce? =

1. Go to **Dashboard → ShopLentor → Modules** and enable **Product Compare**.
2. Open **ShopLentor → Compare** to choose which fields appear in the comparison table.

[Documentation](https://woolentor.com/doc/woocommerce-product-compare/)

= How can I redirect customers straight to checkout in WooCommerce? =

1. Go to **Dashboard → ShopLentor → Modules** and enable **Redirect to Checkout on Add to Cart**.
2. That's it — clicking Add to Cart now sends the customer to checkout and skips the cart page.

[Documentation](https://woolentor.com/doc/redirect-to-checkout/)

= How do I create a multi-step checkout in WooCommerce? =

1. Enable **Multi-Step Checkout** in **Dashboard → ShopLentor → Modules** (Pro).
2. Go to **ShopLentor → Template Builder → Add New Template** and choose the **Checkout** type.
3. Drag in the **WL: Multi-Step Checkout** widget and design your steps.

[Documentation](https://woolentor.com/doc/woocommerce-multi-step-checkout/)

= How do I add a flash sale countdown timer in WooCommerce? =

Enable the **Flash Sale Countdown** module, then set a sale schedule on any product. The countdown appears automatically on product and archive pages. [Documentation](https://woolentor.com/doc/enable-sales-countdown-timer-in-woocommerce/)

= How do I add AJAX search to WooCommerce? =

Enable the **Ajax Search** module, then place the **WL: Ajax Search Form** widget or block wherever you want the search field. Results appear instantly as customers type, with product thumbnails and prices.

= How do I add AJAX add to cart on the product page? =

Enable the **Single Product Ajax Add to Cart** module. Customers can then add products to the cart without a page reload, including variable products.

= How do I add a custom field to WooCommerce checkout? =

Enable **Checkout Field Manager** (Pro), then go to **ShopLentor → Checkout Field Manager**. You can add new fields, edit or reorder existing ones, mark fields required or optional, and remove fields you don't need.

= How do I add a product size chart in WooCommerce? =

Enable the **Size Chart** module (Pro), create a chart under **ShopLentor → Size Chart**, then assign it to products or categories. Display it with the Size Chart widget or block.

= How do I enable backorders in WooCommerce? =

Enable the **Backorder** module, then choose your backorder settings globally or per product. Customers can keep ordering when stock reaches zero.

= How do I make my WooCommerce checkout look like Shopify? =

Enable the **Shopify Style Checkout** module. It replaces the default checkout with a clean two-column layout, with optional theme header and footer control.

= How do I rename labels in WooCommerce? =

Enable the **Rename Label** module. You can rename the Add to Cart button, the Place Order button, and the Description, Reviews and Additional Information product tabs.

= How do I show featured or best-selling products by category? =

Use the **Product Grid**, **Product Slider** or **Product Tab** widget or block, then set the query source to Featured or Best Selling and pick a category. No shortcodes needed.

= Does ShopLentor support digital products and downloads? =

Yes. ShopLentor works with WooCommerce's built-in digital product and downloadable file handling, and the My Account Downloads widget and block let you style the customer downloads area.

= How do I report a security issue? =

Please report security issues to our team directly at **[woolentor.com/contact](https://woolentor.com/contact/?utm_source=wprepo&utm_medium=freeplugin&utm_campaign=security)** rather than in the public support forum.
